# Energy Supply Chain Disruption Tracker

---

## The Problem
Every day, somewhere in the world, energy infrastructure is under threat.
Pipelines explode. Ports get blockaded. Shipping lanes become war zones.
Refineries catch fire. Each event ripples through global oil prices within hours.

This dashboard makes those invisible disruptions visible.

---

## What it tracks
| Disruption Type | Example |
|---|---|
| 🔴 Pipeline outages | Nord Stream explosion, Druzhba pipeline shutdown |
| 🟠 Port blockages | Libyan port strikes, Houston weather shutdowns |
| 🟡 Shipping threats | Houthi attacks in Red Sea, Strait of Hormuz tensions |
| 🔵 Refinery outages | Texas freeze, Venezuelan refinery fires |

---

## Features
- **Live disruption map** — world map with active disruption markers
- **Severity ranking** — disruptions ranked by barrels of supply affected
- **Price impact panel** — how much oil prices moved when each event occurred
- **Historical timeline** — browse past disruptions and their market impact
- **Live oil prices** — current WTI and Brent prices updated in real time
